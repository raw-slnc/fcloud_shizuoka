description=Shizuoka Prefecture Forest Cloud information viewer. Links forest planning map (GeoPackage) with the Shizuoka Forest Cloud API to display forest register details, protective forest records, and project data, and displays the Shizuoka Prefecture forest resource analysis open data (airborne laser survey).
version=1.2.1
author=Hideharu Masai
email=hideharumasai@void.mints.ne.jp
about=Displays forest information from the Shizuoka Prefecture Forest Cloud public system, linked to GeoPackage data created by Shinrinbo Code Converter. Provides a dock panel for browsing forest stand attributes, protective forest records, and forest management data. This plugin is specific to Shizuoka Prefecture. Requires a .gpkg or .shp layer containing a KEY1 field loaded in the QGIS project. The displayed information (protective forest ledger, Mori no Chikara reforestation project, forest management plans, forest land development, the Shizuoka Prefecture forest resource analysis data published on the G空間情報センター, etc.) is sourced from open data published by Shizuoka Prefecture and the Shizuoka Prefecture Forest Cloud, retrieved, processed, and formatted for easy reference in QGIS. / Support: https://paypal.me/rawslnc
about[ja]=静岡県森林クラウドの公開システムと連携し、Shinrinbo Code Converter で作成した GeoPackage データに基づいて林地情報を表示します。林小班属性・保安林記録・経営計画作成箇所をドックパネルで閲覧できます。本プラグインは静岡県専用です。KEY1 フィールドを持つ .gpkg または .shp レイヤーが QGIS プロジェクトに読み込まれている必要があります。表示する保安林台帳・森の力再生事業・経営計画・林地開発、G空間情報センターで公開されている静岡県森林資源解析データなどの情報は、静岡県が公開するオープンデータおよび静岡県森林クラウドの公開データをもとに、QGIS 上で参照しやすいよう取得・加工・編集して表示しています。 / Support: https://paypal.me/rawslnc
changelog=
    1.2.1 - Fixed long status messages widening the panel. Long messages are now shortened with …, and the full text is shown when you hover over them. 森林資源情報 tab: a 地位指数マップ button exports a site index map (GeoTIFF) for スギ and ヒノキ from the displayed mesh and the 林齢 of the 小班 on the forest planning map, using the formula of the Forestry Agency guide on making site index maps from airborne LiDAR data. The growth curve coefficients can be chosen from the guide's example (Tokushima Prefecture yield tables) or values read from the Shizuoka Prefecture height growth curves. The conditions used (base year, measurement year, curve and coefficients) are recorded in the file, and the number of cells where the 森林簿 tree species is not スギ or ヒノキ is reported. (The map can also be used as a site index map in the Morizon Next plugin.)
    1.2.0 - [IMPORTANT] Selecting a large number of 小班 (for example with Ctrl+A on the forest planning map, or Ctrl+A in the 森林簿 table) no longer freezes QGIS. The 森林簿 table now appears immediately even for large selections and reads rows as you scroll, and each column has a fixed width so values no longer wrap onto two lines. 小班 overlapping at the same location (records that differ only in 整理番号, or 小班 of a neighboring municipality overlapping at a boundary) are now added to the selection however the 小班 were selected, so no 森林簿 record at that location is missed. In the 森林資源情報 tab, selecting 小班 on the forest planning map now shows statistics for the selected area (the part covered by the data, with ha材積 and stand density per area of that part) instead of a long list of features, and selecting the whole forest planning map shows statistics for the whole plan. The data types are now メッシュ (grid data) and ポリゴン, chosen by the actual shape of the data, because grid data is stored in different folders depending on the analysis area. Whole-data statistics also show ha材積 and stand density per メッシュ data area. For large tree species polygons, selecting a feature on the map now selects its row in the table. A progress message is shown while a large selection is being processed.
    1.1.0 -Added a 森林資源情報 tab that downloads and displays the Shizuoka Prefecture forest resource analysis open data (静岡県森林資源解析データ on the G空間情報センター): mesh, tree species polygons, single-tree points and 林相識別図. Downloaded data is saved in the project folder and can be viewed without a network connection, and the table lists the features overlapping the 小班 selected on the forest planning map. When no 小班 is selected, the table area shows statistics for the whole data and its overlap with the forest planning map. Tree species names that differ between analysis areas are unified for coloring. Added an option to hide mesh and polygon outlines when zoomed in beyond a chosen scale. 林相識別図 images are stored at a smaller size without any change in appearance. Added a 画面ロック option that keeps the map from panning or zooming when a table row is selected. The selection highlight on the connected forest planning map layer is now easier to see while the panel is open, and the layer's own selection settings are restored when the panel is closed. Fixed the 経営計画 tab's 計画箇所レイヤー button and layer visibility not following tab changes correctly. The manual and the データについて dialog now state that the displayed information is for reference only.
    1.0.3 - Added items to the information displayed in the 選択中の小班 tab and the クラウド情報 tab of the panel. Added a 選択時のズームを無効化 option that keeps the map scale unchanged when selecting a table row.
    1.0.2 - [CRITICAL FIX] Fixed Kozu XML Integrator linkage searches becoming unresponsive after Kozu changed its 大字 list to be grouped by municipality. The linkage now also selects the correct municipality when the same 大字 name exists in multiple municipalities.
    1.0.1 - Improved Mori no Chikara search reliability and result review. "(All years)" searches now complete results beyond the 500-row server limit, newly published implementation-area shapes are fetched automatically, and all project fields are available in the result list and info panel. Copying and horizontal table navigation were also improved.
    1.0.0 - QGIS 4.x support. Added a panel button to add the 静岡県 微地形表現図 background tile layer. Improved shutdown behavior.
    0.2.0 - Improved panel usability and Kozu XML Integrator linkage. [IMPORTANT] Public-map links now prevent municipality / 大字 mismatches and resolve former municipality names to current cities. Stacked forest-register records can be inspected together, 林地開発 and 保安林 search behavior has been adjusted, and protective-forest search / 地番 handling has been improved. Also made small label and spacing adjustments.
    0.1.4 - The connected GPKG/SHP layer no longer follows whichever layer happens to be active in the QGIS layer panel; on launch it restores the previously connected layer from saved settings (or stays empty if not found) and is no longer affected by clicking other layers in the panel. Fixed a bug where closing the dock with its native title-bar close button (rather than the toolbar toggle) prevented the connected layer from being reactivated the next time the dock was reopened. Added a 森林簿 tab section to the manual and reorganized the overview section.
    0.1.3 - Prepared for QGIS official repository submission: replaced a direct urllib call with QgsNetworkAccessManager for the 林地開発 MVT tile fetch, narrowed several broad exception handlers, added logging for previously silent error paths, and removed unused imports/variables
    0.1.2 - On Windows, the dock panel now becomes a true top-level window when undocked/floated, so it appears separately in Alt+Tab instead of being tied to the main QGIS window
    0.1.1 - Fix: dissolve processing no longer adds spurious "output" layers to project; Mori no Chikara symbology now groups legend by maintainer > year > management number
    0.1.0 - Initial release
