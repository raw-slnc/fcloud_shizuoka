# Fcloud Shizuoka

A QGIS plugin that links a forest register GeoPackage with the Shizuoka Prefecture Forest Cloud public API, letting you browse forest stand attributes and cloud-side administrative records from a single dock panel.

This plugin is designed for GeoPackage data generated by **Shinrinbo Code Converter** and is intended for **Shizuoka Prefecture workflows only**.

## Features

- **Layer connection**: Detects loaded `.gpkg` and `.shp` layers that contain a `KEY1` field in the current QGIS project and lets you choose the target layer from a combo box
- **Selected stand viewer**: Shows the attributes of the currently selected forest stand in the left panel
- **Protective forest register search**: Search by city, Oaza, and parcel number, then highlight matching features on the map
- **Forest maintenance project search (整備事業)**: Search the Forest Cloud forest maintenance project records with the same conditions as the Forest Cloud website (fiscal year, project content, type, tree species) and list all matching records, including those beyond the 500-row limit of the website. Records can also be narrowed down to the municipality or the extent of the connected forest planning map, and the current filtered result can be combined into a QGIS layer when a fiscal year and municipality are selected
- **Mori no Chikara search**: Filter records by forestry office, fiscal year, project type, and operator; optionally add the project polygon layer
- **Forest management plan viewer**: Load management-plan statistics and add a plan-area layer to the map
- **Forest land development search**: Search permit / coordination records by category, applicant, purpose, and municipality
- **Forest resource analysis data**: Download and display the Shizuoka Prefecture forest resource analysis open data (airborne laser survey, published on the G空間情報センター): mesh, tree species polygons, single-tree points and 林相識別図. List the features overlapping the selected 小班, and view statistics for the whole data
- **Layer helpers**: Add related map layers such as the forest road MVT layer
- **Local cache**: Save acquired data locally for reuse. Most API caches are stored in the project folder; the 整備事業 search data is shared between projects from the QGIS user profile folder
- **Kozu integration**: Optionally send the 大字 and parcel number to `kozu_xml_integrator` when selecting rows in the 保安林台帳 or 森林簿 tab

## Included tabs

- **森林簿**: Shows Forest Cloud forest-register information for the feature(s) currently selected on the connected layer, in the same field order as the Forest Cloud website. Retrieved records are cached and reused. With a full forest-register GeoPackage, the source button at the left edge shows the current source and switches between **森林クラウド** and local **森林簿** each time it is pressed; local data is also used automatically when the cloud record cannot be obtained. **CSVエクスポート** saves the currently displayed table as a UTF-8 BOM CSV file
- **保安林台帳**: Parcel-based search and matching against the connected GeoPackage
- **整備事業**: Search forest maintenance project records by 年度, 事業内容, 種類 and 樹種. Filter changes, including clearing a condition, are applied immediately, and **全リセット** clears all five filters and the 計画図レイヤーの範囲内だけ option. The table has the same columns and order as the Forest Cloud website, plus a 市町 column. The search uses a bundled lookup list of search conditions and record numbers; rows beyond the first 500 are completed from the Forest Cloud vector tiles and single-record requests, and the number of rows is checked against the total reported by Forest Cloud. Options with no records are grayed out. The 市町 filter and the 計画図レイヤーの範囲内だけ option use the connected forest planning map. Selecting a row shows the project area on the map. When 年度 and 市町 are selected, **統合してレイヤーで見る** combines split geometries for each project record and places the current filtered result in a single QGIS layer
- **森の力**: Search and display project implementation records
- **経営計画**: Load plan summary tables and display plan polygons
- **林地開発**: Search permit / coordination records and optionally add related layers
- **森林資源情報**: Download and display the forest resource analysis open data. Tree species names that differ between analysis areas are unified for coloring

## Requirements

- QGIS 3.44 or later (including QGIS 4.x)
- Internet connection for API access, MVT layer access, and open data downloads
- A forest planning map layer loaded in QGIS:
  - **Full functionality**: GeoPackage generated by **Shinrinbo Code Converter**
  - **Partial functionality**: Shizuoka Prefecture's official Shapefile distribution (forest stand attributes will be incomplete)
- Workflow limited to **Shizuoka Prefecture**

Tested environment:

- QGIS 3.44.15 on Linux
- QGIS 3.44.15 on Windows
- QGIS 4.2.2 on Windows
- QGIS 4.2.2 (Flatpak) on Linux

## Installation

### From the QGIS official plugin repository

1. In QGIS, open **Plugins → Manage and Install Plugins**
2. Search for **Fcloud Shizuoka** and click **Install Plugin**
3. Open the plugin from the toolbar icon or **Vector → 静岡県森林クラウド**

### From ZIP

1. Download `fcloud_shizuoka.zip`
2. In QGIS, open **Plugins → Manage and Install Plugins**
3. Choose **Install from ZIP**
4. Select the ZIP file and install
5. Open the plugin from the toolbar icon or **Vector → 静岡県森林クラウド**

## Basic workflow

1. Open a QGIS project and load the target GeoPackage layer
2. Open **Fcloud Shizuoka**
3. Select the connected `.gpkg` layer in the combo box
4. Use each tab to search Forest Cloud records
5. Select table rows to highlight the corresponding features on the map
6. If needed, save the acquired data locally for reuse in the same project

## Cache behavior

Cached data is stored under the project directory in an `fcloud_shizuoka/` folder.

- **保安林台帳**: SQLite cache by municipality plus Oaza list cache
- **森の力**: SQLite cache by search condition, plus polygon cache
- **経営計画**: SQLite cache plus GeoPackage cache
- **林地開発**: SQLite cache by search condition

The **整備事業** tab does not use the project directory. Its lookup list (when updated with **リストを更新**), the vector tiles it has read, and saved details for records not contained in those tiles are stored in `fcloud_shizuoka/seibi/` under the QGIS user profile folder, and are shared by all projects. Saved details are checked against the current lookup list before reuse.

Data downloaded in the **森林資源情報** tab is stored as GeoPackage / GeoTIFF under `fcapital_data_shizuoka/shared/` in the project directory, and can be viewed without a network connection. One analysis area can be several hundred MB to several GB.

The project should be saved before relying on local cache storage (the **森林資源情報** tab cannot download data until the project is saved).

## Notes

- This plugin is specific to Shizuoka Prefecture data and API endpoints
- Shizuoka Prefecture's official Shapefile distribution can also be used as the source layer, but forest stand attribute data will be incomplete compared to a GeoPackage generated by Shinrinbo Code Converter
- A detailed user manual is included separately as `manual.html`
- Kozu integration sends the 大字 and parcel number of the selected 小班 to `kozu_xml_integrator`. In some areas the 大字 is divided differently on the forest planning map and on the cadastral map (公図) — for example, 大沢里 in 西伊豆町 is divided into 大沢里白川 and 大沢里祢宜畑 on the 公図. In such cases the plugin chooses the 公図 大字 from the parcel number. When the same parcel number exists in more than one of them, the plugin cannot tell which one is meant and does not search; choose the 大字 in `kozu_xml_integrator` and search the parcel number there
- The forest resource analysis data shows the situation at the time of measurement, not the current situation; its accuracy may vary by measurement period (as stated by Shizuoka Prefecture). The displayed information is for reference only
