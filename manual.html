Fcloud Shizuoka 操作マニュアル

QGIS 3.44 以上対応（QGIS 4.x を含む）

概要

Fcloud Shizuoka は、静岡県森林クラウド（fcloud.pref.shizuoka.jp）の公開APIと、 Shinrinbo Code Converter が生成した森林簿 GeoPackage を連携させる QGIS プラグインです。 ドックパネルから保安林台帳・整備事業・森の力再生事業・経営計画・林地開発の情報を検索・閲覧し、 地図上でフィーチャーをハイライト表示できます。

・本プラグインで表示する保安林台帳・森の力再生事業・経営計画・林地開発などの情報は、 静岡県が公開するオープンデータおよび静岡県森林クラウドの公開データをもとに、 QGIS 上で参照しやすいよう取得・加工・編集して表示しています。

・本プラグインの表示は、既存の情報を重ね合わせて閲覧するための参考資料です。 申請・境界の確定・権利関係の判断などの根拠には使用しないでください。 判断は利用者の責任で行ってください。

できること

  • 保安林台帳の地番照合・ハイライト表示
  • 整備事業の検索（500件を超えても全件を表示）
  • 森の力再生事業の検索・実施箇所レイヤー表示
  • 経営計画の読み込み・計画箇所レイヤー表示
  • 林地開発（許可・連絡調整）の検索
  • 森林資源情報（航空レーザ解析のオープンデータ）の取得・表示
  • API取得データのローカルキャッシュ

対象データ

  • 静岡県内の森林簿 GeoPackage
  • 静岡県配布の森林計画図SHP
  • 静岡県森林クラウド公開API
  • MVT（Mapbox Vector Tiles）形式の地理データ
  • G空間情報センター「静岡県森林資源解析データ」
静岡県が配布する森林計画図SHPファイル（KEY1フィールドを含むもの）も 接続レイヤーとして利用できます。SHPには森林簿属性（材積・林齢など）が含まれないため、 小班情報パネルの表示は動作しませんが、市町村名称・地番の各フィールドが含まれていれば 保安林台帳の地番照合・ハイライト機能は利用できます。 森の力・経営計画・林地開発のAPI検索およびレイヤー表示も利用可能です。 完全な機能（小班情報パネル含む）を利用するには、Shinrinbo Code Converter で作成した GeoPackage（GPKG）の使用を推奨します。

森林簿

条件を指定して検索するタブではなく、地図上（接続中の GPKG/SHP レイヤー）で選択したフィーチャーの 森林簿情報を一覧表示するタブです。既定では森林クラウドから取得し、本家サイトと同じ項目順で表示します。 取得済みの情報はキャッシュから再利用します。複数フィーチャーを選択した場合は、選択した数だけ行が表示されます。

上部左端のボタンが現在の表示元です。「森林クラウド」が既定で、押すたびに 「森林クラウド」と「森林簿」が切り替わります。森林簿属性を含む GeoPackage で利用できます。 森林クラウドから取得できないときは「森林簿」へ自動的に切り替えて表示します。
「CSVエクスポート」は、現在のテーブルの列と行を表示順のまま保存します。 ファイルはExcelでも開きやすい UTF-8 BOM付きCSVです。
森林クラウドの読み込み中は、テーブル上部の空き領域に処理済み件数・総件数・進捗率を表示します。 読み込み中だけ表示される「中止」を押すと、新しい取得要求を止めます。すでに通信中のまとまり（最大6件）は 完了まで待ってから停止し、その時点でクラウド情報を取得済みのフィーチャーと表の行だけを残します。 未取得のフィーチャーは選択解除されるため、不用意に多数の小班を選択した場合も、処理済みの区切りで止められます。 読み込みが完了すると進捗と「中止」は消え、右下の取得日時が更新されます。
小班を選ぶと、同じ場所に重なっている小班（整理番号違いの小班や、市町村の境目で重なっている別の小班など）も 自動で選択に加え、表に並べます。同じ場所の森林簿を見逃さないためで、クリックで選んでも式で選んでも、 選んだ件数によらず同じです。 数千件以上をまとめて選ぶと、重なりの確認に時間がかかります（全件を選んだときは確認しません）。

行選択とハイライト

テーブルの行を選択すると、対応するフィーチャーの位置に地図がズームし、ハイライト表示されます（「選択時のズームを無効化」がオンの場合は、縮尺を変えず中心だけを移します）。

「公図連携 ON/OFF」ボタンを ON にすると、行選択のたびに kozu_xml_integrator へ大字・地番を自動送信します （詳細は公図連携参照）。

所有者情報の表示と自動伏せ字

「森林簿属性を含む GeoPackage」に 登記所有者_漢字（名前）と 登記所有者_住所（住所）の列がある場合、 小班を選択すると「所有者情報」として名前と住所を表示します。 表示する場所は、「選択中の小班」タブの基本情報の末尾と、「クラウド情報」タブで森林簿の行を選択したときの下部です。 「クラウド情報」タブでは、「森林クラウド情報」との間に区切り線を入れ、「計画図レイヤー情報」の見出しの下に表示します （森林クラウドから取得した情報ではなく、接続中のレイヤーに含まれる情報です）。 「CDのみの GeoPackage」と「森林計画図SHP」では表示しません。

所有者情報は取り扱いに注意が必要な情報のため、QGIS で約 3 分間操作がないと、名前と住所を「＊＊＊＊＊＊＊」に自動で伏せます。 QGIS 上でマウスやキーを操作すると、元の表示に戻ります（他のアプリケーションでの操作は含みません）。 伏せている間は、「全項目をコピー」などのコピー操作でも、伏せ字のままコピーされます。

簡易的な覗き見対策です。操作すれば元に戻るため、席を離れるときは OS の画面ロックを併用してください。 同じ列の内容は、QGIS 標準の属性テーブルや識別結果にも表示されますが、これらは伏せ字の対象外です。 伏せ字になる前にクリップボードへコピーした内容も対象外です。

整備事業

森林クラウドの「整備事業」（間伐・下刈・人工造林などの森林整備事業の記録）を、 森林クラウドのサイトと同じ条件（年度・事業内容・種類・樹種）で検索します。 森林クラウドのサイトは、条件に合う整備事業を 500 件までしか表示しませんが、 このタブは 500 件を超えても全件を表示します。

行選択と地図

表の行を選択すると、その整備事業の区域を地図上でハイライトしてズームします （「選択時のズームを無効化」「画面ロック」に従います）。 森林クラウドの地図タイルに区域の形が無い整備事業は、より細かい縮尺のタイルで探し、 それでも無いときは森林クラウドが示す位置に印を出して、表の上に「形がありません」と表示します。

500 件を超える検索の仕組み

森林クラウドの検索は、条件に合う先頭の 500 件と総行数だけを返します。このタブは、 プラグインに同梱した検索軽量化リスト（検索条件と整備事業の番号の対応表。区域の形や面積などの値は含みません）を使い、 501 件目からは、その番号の整備事業が入っている森林クラウドの地図タイルと、1 件ずつの取得で補います。 表示する値はいつも森林クラウドから取得したものです。

検索するたびに、森林クラウドが返した結果と検索軽量化リストを照合します。違いが見つかったときは、 表の上に「リストを更新」を押すよう表示します。「リストを更新」は、増えた番号だけを取得して書き足します。 番号が減った・抜けたときは、確認のうえで作り直します（静岡県全体の地図タイルを読み直すため、数分かかります）。 更新中にもう一度押すと中止します（中止したときは前のリストのまま使います）。
検索軽量化リスト、読み込んだ地図タイル、タイルに無い案件の表示内容は、プロジェクトフォルダではなく、QGIS のユーザープロファイルのフォルダ （fcloud_shizuoka/seibi/）に保存し、すべてのプロジェクトで共通に使います。 タイルに無い案件の表示内容は、現在の検索軽量化リストと一致することを確認してから再利用します。 下部の「ローカル保存」「更新」はこのタブでは使いません。下部には検索軽量化リストの作成日と件数を表示します。
2026 年 11 月時点で、森林クラウドの整備事業のデータは 2022 年度（令和 4 年度）までです。 年度の選択肢には 2023 年度以降も表示されますが、灰色で選べません。

「実施箇所レイヤー」ボタンを ON にすると、MVT から取得した実施ポリゴンをレイヤーとして追加します。 取得済みのキャッシュがある場合はすぐに表示され、ない場合は静岡県全域のタイルを取得します（初回は時間がかかります）。

統計を出すのはメッシュと単木ポイントです。ポリゴンは統計を出さず、小班を選ぶと、その小班の中にある地物を表に出します。 ただし、樹種ごとにまとめた大きな形のポリゴンは、1件が広い範囲にまたがるため、小班で選ぶことはせず、全件を表に出します。 このときは、地図で地物を選ぶと、表のその行を選んでそこまで表を送ります。

選択中の範囲の統計

計画図レイヤーで選んだ小班の範囲にある、表示中のデータ（メッシュ・単木ポイント）を集計します。 出す項目は、このデータにかかる部分の面積、セル数（単木ポイントは本数）、材積のある森林の面積、材積合計、ha材積、立木本数・立木密度、平均樹高・平均直径、樹種ごとの数です。

  • このデータにかかる部分は、選んだ小班のうち、データのある範囲に入る部分の面積です。 小班の数ではなく場所の広さで表すので、同じ場所に重なっている小班（枝番・整理番号違いなど）も1回だけ数えます
  • セル（単木ポイントは点）の中心が小班の中にあるものを集計します。小班の境界にかかるセルは、中心の位置でどちらかに振り分けます。 単木ポイントなどは、数 m の細かさで中心の位置を見たおおよその値です
  • ha材積・立木密度は、範囲の面積（このデータにかかる部分）で割ります。広葉樹の多い範囲ほど小さくなります

データ全体の統計

何も選んでいないときは、表示中のデータ（メッシュ・単木ポイント）全体の統計を出します。 セル数（単木ポイントは本数）、メッシュデータの面積、材積のある森林の面積、材積合計、ha材積、立木本数・立木密度、平均樹高・平均直径、樹種ごとの数と、 計画図との重なり（範囲にかかる市町・林班の範囲・小班数）です。統計は初めて開いたときだけ時間がかかり、次からは保存した結果を出します。

  • ha材積・立木密度は、次の2通りを並べて出します。選択中の範囲の統計と比べるときは「メッシュデータの面積あたり」を見てください
    • 材積のある森林あたり：スギ・ヒノキ類など、材積が入っているセルの面積で割ります
    • メッシュデータの面積あたり：広葉樹なども含めたデータ全体の面積で割ります
  • 平均樹高・平均直径は、材積のあるセルだけで求めます（広葉樹などのセルは樹高・直径が 0 のため）。選択中の範囲の統計でも同じです
  • 面積の列が無いメッシュでは、格子の数 × 格子の面積をメッシュデータの面積とします。本数の列が無いメッシュでは、立木本数・立木密度は出しません
統計は、本プラグインが求めたものです。データに入っている値（ha材積・立木密度などの列）をそのまま使うのではなく、 解析範囲ごとに違うデータの形（20m 四方のセル、小班ごとの集計など）を、本プラグイン独自の統一した方式で集計しています。 そのため、データに入っている値や、森林簿の値とは一致しないことがあります。
このタブを開いているあいだ、左パネルの「クラウド情報」タブは「資源情報」になり、選んだデータの内容（範囲にかかる市町、計測年度、林相識別図の有無と容量、取得状況など）を表示します。

地位指数マップ

下部の「地位指数マップ」ボタンで、表示中のメッシュ（スギ・ヒノキ）の樹高と、小班の林齢から、 地位指数（林齢40年時の樹高）を求め、GeoTIFF に書き出します。 式は、林野庁「航空機 LiDAR データを使った地位指数分布図の作成の手引き」（2022年3月）の作業8と同じ（ミッチャーリッヒ式）です。 書き出したファイルはふつうの GeoTIFF です（Morizon Next プラグインの地位指数マップとしても使えます）。

ボタンを押せるのは、メッシュ（10m・20m 四方）のデータを表示していて、そのデータに樹種と樹高の列があるときです。 押せないときは、ボタンにマウスを置くと理由が出ます。

表示と保存

表示できるデータは1つだけで、別のデータを表示すると、前のデータと入れ替わります。

データはプロジェクトフォルダ内の fcapital_data_shizuoka/shared/ に保存します。QGIS プロジェクトが保存されていない場合は取得できません。 データは大きく、プロジェクトフォルダが同期フォルダ（Dropbox など）にある場合は同期の対象になる点に注意してください。
静岡県は、このデータの精度は計測時期等により異なる場合があり、作成時点の現況を示すもので現在の現況ではない、としています。 メッシュのスギ・ヒノキ類以外のセルでは、立木本数・樹高などの値は 0 です。 座標系の情報が付いていないデータ（一部の解析範囲のもの）は、平面直角座標系 第VIII系（JGD2011）として読み込みます。
パソコンについて

森林に関する情報は、大きなデータを扱います。特に「森林資源情報」タブで扱う航空レーザ解析のデータは、 1つの解析範囲で数百MB〜数GBになります（例：賀茂地区の5範囲で、林相識別図を含め約9GB）。

本プラグインでは、軽く動かすために次のことを行っています。

  • 取得したデータは、空間インデックス付きの GeoPackage として保存し、2回目からは回線を使わずに素早く読み込む
  • 林相識別図は、見た目を変えずに容量を減らし、縮小表示用の画像（ピラミッド）を付けて保存する
  • 表に出すのは、計画図で選んだ小班にかかる地物だけにする
  • 地図に表示する森林資源情報は、常に1つだけにする
  • 取得や変換は裏側で行い、その間も QGIS を操作できるようにする

それでも、次のような場面では、パソコンの性能によって待ち時間が大きく変わります。

  • データの取得（回線の速さ）と、取得後の変換（ディスクの速さ・CPU のコア数）
  • 林相識別図や単木ポイント（数十万〜数百万点）を、広い範囲で表示するとき
  • 大きなデータを、ほかのレイヤーと重ねて表示するとき

一般的な事務作業向けのパソコンより、次のような余裕があるほど快適になります。

  • メモリに余裕がある
  • データを保存するドライブが SSD である
  • 保存先のドライブの空き容量に、取得するデータの数倍の余裕がある（取得の途中で一時ファイルを使います）
  • CPU のコア数が多い（林相識別図の変換が速くなります）

森林クラウドのタブ（森林簿・保安林台帳など）だけを使う場合は、これほどの性能は必要ありません。

大字の決め方

同名の大字は計画図の市町村で絞ります（市町村が不明なら同名の全公図が対象）。計画図と公図で大字の分け方が違う場合は、 同じ市町村で名前の前方が一致する候補から地番で決めます。例：西伊豆町の「大沢里」→「大沢里白川」「大沢里祢宜畑」。

場合動作
大字名が公図と一致するそのまま検索します（伊豆市の「大平」と「大平柿木」のように、計画図でも別の大字のものは区別されます）。
地番がある公図の大字が 1 つに決まるその大字で検索し、メッセージバーに知らせます。
同じ地番が複数の公図の大字にあるどの公図か決められないため検索せず、知らせを表示します。kozu_xml_integrator で大字を選んでから、地番を検索してください。
該当する公図の大字が無い「Kozu XML Integrator の DB に存在しません」と表示します。
公図連携を ON にしたとき、大字の違いに関する注意を一度表示します。「次回から表示しない」を選べます。 計画図と公図の大字の対応は、全地域で確認済みではありません。

静岡県 微地形表現図森林クラウドの背景タイル（CS立体図）。追加済みならボタンは無効。終了後も通常のレイヤーとして残ります

各タブのレイヤーボタン（実施箇所・計画箇所・林地開発）で追加したレイヤーは、そのタブを開いているあいだだけ表示されます。

動作要件

項目要件
QGIS バージョン3.44 以上（4.x 系を含む）
動作確認環境QGIS 4.2.2（Windows、Linux は Flatpak 版）
インターネット接続必須（API・MVTタイルへのアクセス）
GeoPackageまたはShapefileShinrinbo Code Converter で生成した静岡県森林簿データ
または静岡県配布の森林計画図SHPファイル
対象地域静岡県内のみ

インストール

QGIS公式リポジトリからのインストール手順（推奨）

  1. QGIS のメニューから プラグイン → プラグインの管理とインストール を開く
  2. 「すべて」タブで Fcloud Shizuoka を検索する
  3. プラグインをインストール をクリックする
  4. インストール後、ベクタツールバーに森林クラウドアイコンが追加される

ZIP からのインストール手順

  1. 配布された fcloud_shizuoka.zip をダウンロードする
  2. QGIS のメニューから プラグイン → プラグインの管理とインストール を開く
  3. 左側の「ZIP からインストール」タブを選択する
  4. 「…」ボタンで先ほどの ZIP ファイルを選択し、プラグインをインストール をクリックする
  5. インストール後、ベクタツールバーに森林クラウドアイコンが追加される
インストール直後はドックパネルが非表示です。ツールバーのアイコン、またはメニュー ベクタ → 静岡県森林クラウド をクリックして表示します。

アップデート

QGIS公式リポジトリからインストールした場合は、 プラグインの管理とインストール → アップグレード可能 に表示され次第、通常のプラグインと同様に更新できます。 ZIP からインストールした場合は、新しい ZIP を配布された際に同じ手順で上書きインストールしてください。 または プラグインの管理とインストール → インストール済み から Fcloud Shizuoka を一度アンインストールしてから再インストールしてください。
